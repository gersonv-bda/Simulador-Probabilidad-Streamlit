# 🪙 Simulador Estadístico de Lanzamiento de Monedas

### Visualización de la Ley de los Grandes Números

Esta aplicación es una herramienta de simulación estadística diseñada para demostrar cómo los promedios de resultados aleatorios convergen a medida que aumenta el número de experimentos. Es un ejemplo práctico de computación aplicada a la estadística descriptiva.

---

## 📊 Cómo funciona
1.  **Generación de Datos:** El sistema simula lanzamientos de monedas de forma aleatoria.
2.  **Cálculo Acumulativo:** Se registra el resultado de cada tirada y se calcula el promedio de "Caras" o "Cruces" en tiempo real.
3.  **Visualización:** Los datos se presentan en una tabla dinámica que se actualiza con cada iteración, permitiendo observar la estabilización de la probabilidad.

---

## 🛠️ Stack Tecnológico
* **Python:** Lógica matemática y simulación.
* **Streamlit:** Interfaz de usuario interactiva.
* **Pandas:** Estructuración y manejo de la tabla de resultados.
* **Scipy:** Distribuciones estadísticas, funciones matemáticas y análisis de datos.
